      Profile fit

      Specificity, not probability

      An actor linked to a narrow set of sectors or countries scores more strongly than an actor linked broadly across the source. Sector and country remain independent historical attributes.

      Analytic confidence

      Separate from relevance

      Actor rankings use historical public reporting. Validate priorities against current intelligence before operational use, even when profile fit is focused.

      Detection content

      Schema reviewed, tenant tested later

      KQL tables and projected fields are reviewed against Microsoft Learn. Every hunt still requires data-availability checks, false-positive review and tenant tuning.

      Scope controls

      Dated evidence and analytical focus

      The selected window applies only to source publication dates, ATT&CK last_seen and CISA dateAdded. Top-N focus recalculates downstream priorities and retains all score ties.

      Current signals

      Human-reviewed provenance

      The dated signal layer uses authoritative source claims with explicit entity types and caveats. It complements the historical score and never silently changes it.

      Refresh model

      Automated where defensible

      ATT&CK, MISP targeting context and CISA KEV refresh automatically every six hours through GitHub Actions. Current signals require human review; GitHub may pause schedules after 60 days without public-repository activity.

      Take the assessment with you

      Save a concise decision report, export the complete data, or continue analysis in ATT&CK Navigator. PDF and complete JSON exports are created locally and may include organisation or technology text entered—review them before sharing. Navigator exports exclude both fields.

      Evidence boundary. This workbench assesses profile relevance from public structured intelligence. It does not claim direct targeting, confirmed exposure or production-ready detections without the supporting evidence.
